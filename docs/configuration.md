# Configuration Reference

`~/.config/ghostty/config` holds behaviour only. Font, colours and opacity are included from
`~/.config/aco/theme/ghostty/theme`, generated by [aco-theme](https://github.com/Akademie-Olympia/aco-theme)
from `aco-theme/theme.tpl`.

---

## Theme

```ini
config-file = ~/.config/aco/theme/ghostty/theme
```

- Font `JetBrainsMonoNL Nerd Font` 10.5, 16 terminal colours, selection and an accent cursor follow
  `aco-theme mode|accent|transparency`; running windows reload on SIGUSR2.
- `background-opacity` is `term_opacity` (0.94) with transparency on, 1 with it off.

## Typography

```ini
font-feature = -calt
font-feature = -liga
```

Ligatures are off, so `==`, `->` and `!=` always stay separate characters.

## Window and behaviour

```ini
command = /usr/bin/zsh
window-decoration = none
gtk-titlebar = false
window-padding-x = 10
window-padding-y = 10
window-padding-balance = true
confirm-close-surface = false
mouse-hide-while-typing = true
shell-integration-features = no-cursor
cursor-style = bar
cursor-style-blink = false
```

## Customising locally

Behaviour: edit `~/.config/ghostty/config` and reload with <kbd>Ctrl+Shift+,</kbd>.
Colours or fonts: put tokens into `~/.config/aco/theme.local.conf` (for example `mono_size = 12`) and run `aco-theme apply`.
